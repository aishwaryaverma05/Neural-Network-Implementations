# IMDB Movie Review Sentiment Analysis Using Simple RNN

## Overview
This project implements a Simple Recurrent Neural Network (RNN) using Python and TensorFlow to classify IMDB movie reviews as positive or negative.

## Objective
To apply deep learning and Natural Language Processing (NLP) techniques to sentiment analysis using sequential text data.

## Technologies Used
- Python
- TensorFlow / Keras
- NumPy
- Kaggle Notebooks

## Workflow
1. **Dataset Loading:** Load the IMDB movie review dataset for sentiment classification.
2. **Text Preprocessing:** Convert text reviews into numerical sequences and prepare them for model input.
3. **Sequence Padding:** Make input sequences a consistent length for neural network training.
4. **Model Building:** Implement a Simple RNN architecture using TensorFlow/Keras.
5. **Model Training:** Train the model to identify patterns in movie reviews.
6. **Sentiment Prediction:** Classify reviews as positive or negative.

## Key Learnings
- Understanding recurrent neural networks and sequential data.
- Applying text preprocessing and sequence padding for NLP tasks.
- Implementing and training a deep learning model using TensorFlow.
- Understanding binary sentiment classification.
