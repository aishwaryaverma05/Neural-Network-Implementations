# Breast Cancer Classification Using ANN

## Overview
This project implements an Artificial Neural Network (ANN) using Python and TensorFlow to classify breast cancer cases using a structured dataset.

## Objective
To practice neural network implementation and apply deep learning to a binary classification problem.

## Technologies Used
- Python
- TensorFlow
- NumPy
- Pandas
- Scikit-learn
- Kaggle Notebooks

## Workflow
1. **Data Preparation:** Load the dataset and prepare features and target labels.
2. **Preprocessing:** Prepare the data for neural network training.
3. **Model Building:** Implement an Artificial Neural Network using TensorFlow.
4. **Model Training:** Train the network on the prepared dataset.
5. **Evaluation:** Evaluate the model using the metrics implemented in the notebook.

## Key Learnings
- Understanding ANN architecture and layers.
- Practicing neural network training using TensorFlow.
- Applying deep learning to a binary classification task.
